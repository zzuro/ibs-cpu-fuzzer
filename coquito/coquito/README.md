# COQUITO

COQUITO is a minimal OS stub. It aims at helping me add simultaneous multi-guest support to COCONUT: COQUITO simply
outputs a message (`PING<newline>`) on the serial console, demonstrating that it could boot. That's all.

Most of the code has been taken and adapted from [the OSDev Wiki](https://wiki.osdev.org/Main_Page).

The name COQUITO comes from a very small species of coconuts. See [the corresponding Atlas Obscura entry](https://www.atlasobscura.com/foods/coquito-nuts-mini-coconuts).
